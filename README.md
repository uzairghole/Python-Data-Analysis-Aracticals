## Project Code Overview

### 1. Histogram Visualization

Generates 1,000 normally distributed exam scores with a mean of 70 and a standard deviation of 10. The program visualizes the score distribution using a histogram with 17 bins and displays a vertical dashed line representing the calculated mean.

### 2. Trigonometric Function Plotting

Generates 100 evenly spaced points between 0 and 10 to plot sine and cosine functions on the same graph. The visualization includes labeled axes, a legend, and a grid to make comparison between the two trigonometric functions clear and easy to understand.

### 3. NumPy Array Fundamentals

Demonstrates fundamental NumPy array creation techniques using functions such as `zeros()`, `ones()`, `arange()`, and `linspace()`. It also explores important array properties including `shape`, `dtype`, and `ndim`, along with reshaping a one-dimensional array into a 3 × 4 matrix.

### 4. Array Slicing and Masking

Demonstrates different techniques for accessing, selecting, and filtering data in NumPy arrays. The program covers basic indexing and slicing, 2D row and column selection, fancy indexing using coordinate lists, and Boolean masking for filtering values based on conditions such as scores greater than or equal to 70.

### 5. Pandas DataFrame Essentials

Introduces the fundamentals of Pandas DataFrames by creating a structured dataset from a custom dictionary. The program demonstrates column and Series selection and uses methods such as `.shape`, `.dtypes`, and `.describe()` to inspect the structure, data types, and statistical summary of the dataset.

### 6. Data Wrangling and Aggregation

Demonstrates practical data manipulation and analysis techniques using Pandas. The program performs conditional filtering, sorting, calculated column creation, grouping, and aggregation. It also calculates department-wise averages and demonstrates how to drop and rename DataFrame columns.
